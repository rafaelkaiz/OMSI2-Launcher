# OMSI 2 options reference

What each key of the `options.cfg` of OMSI 2 and of the option presets (`option_presets\*.oop`) means, which control of the launcher edits it and what a preset does with it. The tables of keys are generated by `tools\gen_options_doc.ps1` from the launcher code, the English texts of OMSI and the files of a real installation, so they can be regenerated after a change.

Counts are over **68 files**: the options.cfg of the installation and the option presets that OMSI 2 and its add-ons install. A preset has the same format as options.cfg.

## File format

- A key is a line `[name]`; the lines under it, until a blank line, are its values.
- A key with **no value lines** is an on/off switch: present means on, absent means off. Some are inverted (`no_...`): present means the feature is off. The "How" column says which.
- Comment lines such as ` GENERAL ------------------------ ` only group the keys; OMSI writes the keys in its own order.
- The files are plain Windows-1252 text with CR LF line ends. The launcher keeps every line it does not edit exactly as it was.

## What loading a preset does (checked against OMSI 2 itself)

The launcher loads a preset as OMSI does. This was checked by loading test presets in the game and reading `options.cfg` afterwards.

| Case | What happens |
| --- | --- |
| A key the preset has, edited by the Options window (including language, last map and last driver) | It is copied, and the start screen follows the new map and driver. |
| An on/off box of the Options window that the preset does not have | It is switched **off**. |
| `radio` or `screenratio` (a radio link, a manual screen ratio) that the preset does not have | It is **removed**: they only exist while in use. |
| `texture` | Copied from the preset. |
| `nopreview`, `texFilter`, `font_typewriter`, `Editor_LinkAerial`, `no_tex_low_high_switch`, `gamectrleron` | **Not touched** by a preset, in either direction. |
| Any other value the preset does not have (older presets do not know newer options) | Kept as it was. |

Nothing is written to `options.cfg` until the user saves (Options, OK, or Start); a backup is made first, and the 3 newest are kept.

## Keys the game saves itself

No tab of the Options window edits these; OMSI writes them while you play or from its other windows.

| Key | Meaning | Values seen | In files |
| --- | --- | --- | --- |
| `last_map` | last map chosen on the start screen (`maps\<map>\global.cfg`) | free text | 68/68 |
| `last_driver` | last driver chosen (`Drivers\<name>.odr`) | free text | 68/68 |
| `currWeather_ICAO` | weather station (chosen inside the game) | free text | 68/68 |
| `nopreview` | hide the bus previews when choosing a vehicle inside the game | on/off: present = on | 18/68 |
| `gamectrleron` | game controller switched on; OMSI sets it itself when it finds a wheel or pad | on/off: present = on | 27/68 |
| `no_tex_low_high_switch` | switching between low and high resolution textures | on/off: present = on | 5/68 |
| `font_typewriter` | font used for the typewriter texts | Courier New | 63/68 |
| `texFilter` | texture filter: two values | 3; 16 | 63/68 |
| `texture` | texture setting: two values (0 and 1 in every preset of OMSI) | 0; 1 | 68/68 |
| `Editor_LinkAerial` | address used by the map editor to get aerial pictures (contains a key of the map service; do not share it) | an address | 63/68 |

## Not covered yet

The launcher does not edit the **Keyboard**, **Game Controller** and **Addons** tabs of the Options window of OMSI (use the game's own window for those).
